# Constante — protótipo de app de hábitos

Protótipo navegável (HTML, CSS e JavaScript puro, em um único arquivo) de um aplicativo de hábitos com check diário e acompanhamento de progresso.

Desenvolvido para a disciplina **Imersão Profissional: Projeto e Aplicação do Design Digital e a Experiência do Usuário** — UNIASSELVI.

## Telas

1. **Abertura / login**
2. **Hoje** — check diário dos hábitos, anel de progresso e opção de desfazer
3. **Novo hábito** — fluxo-chave, com validação de nome e dias, ícone/cor e lembrete
4. **Confirmação** — resumo do hábito criado
5. **Progresso** — sequência, desempenho semanal, calendário do mês e taxa por hábito
6. **Perfil**

## Como ver

Abra o `index.html` em qualquer navegador — não há dependências nem etapa de build. No desktop o protótipo aparece dentro de uma moldura de celular, com um mapa de telas ao lado; em telas pequenas ocupa a tela inteira.

Também é possível navegar direto para uma tela pela URL: `#login`, `#hoje`, `#novo`, `#criado`, `#progresso`, `#perfil`.

## Tecnologias

- HTML, CSS e JavaScript (sem frameworks)
- Fontes Fredoka e Nunito (Google Fonts)
- Formas e ícones desenhados em SVG

> Os dados exibidos (usuária, hábitos e estatísticas) são fictícios.
